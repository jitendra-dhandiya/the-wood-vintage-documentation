## Duties / compliance

## Logistics
- Prepaid vs COD: ~60% of Indian e-commerce is COD; COD return rate ~26% vs prepaid <2% (trackvid.in / vyora.ai blogs - ESTIMATE). Use partial-advance COD (decision 0027 notes delivery-charge deposit path exists).
- Furniture return rate 15-23% (visual mismatch or transit damage); ~7.6% pieces arrive scuffed (ESTIMATE, blog sources) - invest in packaging. https://www.icarry.in/pages/blog/furniture-shipping-india-avoid-oda-damage-costs.html
- Bulky delivery: ODA (out-of-delivery-area) surcharges; local Jodhpur furniture transport INR 1,700-3,100 for large pieces short-haul (ESTIMATE).
- Made-to-order lead time: owner input needed.
