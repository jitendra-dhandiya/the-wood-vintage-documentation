# Decision Records

One file per non-trivial architectural/product/marketing/SEO decision, named
`NNNN-short-title.md` (zero-padded, sequential). Use this format (MASTER-PROMPT §40):

```
# NNNN. Title

Date: YYYY-MM-DD

## Decision
What was decided.

## Why
The problem/context that forced a decision.

## Alternatives considered
What else was on the table, and why it was passed over.

## Chosen approach
The concrete approach taken.

## Consequences
What this makes easier, harder, or forecloses. Follow-up work it implies.
```

Never rely on conversation memory alone for decisions that will constrain future work — write
them here.
