# SEO Rules

Non-negotiables from MASTER-PROMPT §5–6, §31 — keep these in mind for every page/route added:

- Every page: unique title, unique meta description, canonical URL, correct heading hierarchy,
  semantic HTML, structured data, optimized images with descriptive alt text, internal links,
  breadcrumbs, indexability controls, social metadata, appropriate schema (Product, Organization,
  WebSite, Breadcrumb, Article, FAQ where appropriate, Review only where legitimate).
- **Never** generate fake reviews or fake ratings.
- Programmatic SEO pages (material/room/style/country/use-case) must provide real user value —
  not keyword-stuffed spam pages (§5).
- International SEO: country targeting, hreflang, localized URLs, country-specific metadata —
  URL architecture decision (`/in/`, `/us/`, etc. or alternative) must be evaluated for SEO,
  maintainability, localization, canonicalization, hreflang, analytics, scalability, and
  **documented as a decision record** before implementation (§31).
