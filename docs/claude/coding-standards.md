# Coding Standards

Full coding standards, naming conventions, and API standards already exist in
`../../../backend/CLAUDE.md` §9–12 (Coding Standards, Naming Conventions, API Standards, Folder
Guidelines) and §27–28 (Coding Rules, Do's and Don'ts) — copied from Unique Dressup and applicable
as-is since `wood-vintage` started as a direct copy of that codebase.

This file only needs entries where `wood-vintage` **diverges** from that reference (e.g. new
conventions introduced for the country/currency/handicraft domain). Nothing diverges yet.

General principle carried over from MASTER-PROMPT §36: SOLID, DRY, clean architecture, separation
of concerns, reusable services/components, strong validation, predictable error handling, typed
interfaces, meaningful naming — no unnecessary abstractions.
